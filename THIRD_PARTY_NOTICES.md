This integration is licensed under Apache-2.0 (see `LICENSE`). It ports to
JavaScript the approach of the following project; no code is copied verbatim,
but the endpoints, the parameters, the error messages of the API and their
meaning, and the shape of the node answers follow it.

## pyairvisual

- Project: https://github.com/bachya/pyairvisual
- Used for: the AirVisual cloud API v2 endpoints (`nearest_city`, `city`),
  the `key` parameter, the error messages (`incorrect_api_key`,
  `api_key_expired`, `call_limit_reached`, `city_not_found`,
  `no_nearest_station`, `node not found`...) and their classification, the
  AirVisual Pro / Node cloud endpoint and its answer fields.
